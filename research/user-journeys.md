# Observed customer journeys

1. **Search purchase (primary).** Home hero search → type "moroc" → suggestion → country page → default "Best Choice" plan preselected → sticky summary → Go to Checkout (checkout not inspected: robots.txt).
2. **Browse.** Header "Destinations" → overlay tabs → Top 10 grid with "from" price → country page.
3. **Regional discovery.** Country page bottom "regional plans" upsell (Global, Asia & Oceania) → region page → "View country list (35)".
4. **Compatibility check.** Plan page "Device Compatibility" button / dialog footer "Is your device eSIM compatible?" → device list by brand.
5. **Post purchase (from text).** Web: QR code emailed instantly; App: eSIM in profile → install → enable data roaming → auto-activation on arrival or after 180 days → monitor usage, top up in app.
6. **Referral.** Footer/home band → refer page → code shared in app.

Pain point evidenced in a public App Store review: users forget to install before travel and to enable roaming. BLEUSIM should surface a "Install before you fly" checklist and roaming reminder in order confirmation, email, and app.
