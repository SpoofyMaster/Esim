# Conversion analysis (Saily)

Strengths: search in the first viewport; preselected recommended plan; price visible on every card; sticky checkout CTA; trust line next to CTA (rating, secure payment); activation-later reassurance (180 days) reduces "buy now" anxiety; regional upsell; promo strike-through; FAQ answering objections.

Weak spots BLEUSIM can beat: checkout handled after leaving the plan page (extra step); no visual sense of coverage (lists only); web account management is thin (app-centric); generic stock photography.

BLEUSIM rules: no invented ratings/reviews/stat counts; show only verified provider facts; keep plan → checkout to one screen on mobile (bottom sheet); show "install before you fly" + roaming toggle guidance before payment.
